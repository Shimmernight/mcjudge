> 肃静！麦门最高裁判所现在开庭。
> 你只需说出你的麦当劳吃法，判官将逐条取证、锐评，宣判你的**麦门纯度**与**段位**——
> 然后，慈悲为怀，用麦当劳 MCP 的**真实优惠券**为你凑一套「救赎套餐」。

**麦门！**

本项目是 [2026 麦当劳程序员创意开发大赛](https://github.com/M-China/mcd-developer-innovation-challenge) 参赛作品，基于麦当劳官方 MCP 能力开发。

## 🎬 这是什么

- **你说吃法，判官开庭**：例如「巨无霸套餐加中薯，可乐去冰，薯条蘸圆筒，麦门永存」
- **逐条取证**：每个细节都有判词——虔诚加分，异端扣分
- **宣判纯度与段位**：从「麦门路人」到「麦门之神」共 6 个段位，截图即传播
- **救赎套餐**：调用麦当劳 MCP 查询你账户的真实优惠券 + 附近门店 + 菜单，算出券后价，把「审判」变成一次真实可用的省钱点餐
- **双模式**：不配 MCP Token 也能玩（离线判决）；配置后解锁完整救赎流程

## 🚀 快速开始

### 离线模式（无需任何配置）

```bash
python3 scripts/judge.py "麦辣鸡腿堡加中薯加可乐，麦门永存"
python3 scripts/judge.py --json "你的吃法"   # JSON 输出，方便集成
```

纯 Python 标准库，无需安装任何依赖；同一输入永远得到同一判决（可复现的正义）。

### 完整模式（WorkBuddy + 麦当劳 MCP）

1. 前往 [麦当劳 MCP 开放平台](https://mcp.mcd.cn) 用手机号登录，在控制台申请 MCP Token
2. 打开 WorkBuddy →【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】，粘贴（替换 Token）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

3. 启用 `mcd-mcp` 连接器，把本仓库 `skill/` 目录作为技能导入 WorkBuddy
4. 对 WorkBuddy 说：「我要接受麦门审判：巨无霸去酱，可乐兑雪碧」，然后等待宣判与救赎套餐

其他支持 Streamable HTTP 的 MCP Client（Cherry Studio / Cursor / Trae 等）同样可用，把 `skill/SKILL.md` 的内容作为系统提示词/项目规则接入即可。

## 🛠️ 设计思路

**玄学是皮，MCP 是骨，省钱是心。**

1. 「麦门文学」是中文互联网的经典梗，人人都能参与——判决结果是天然的社交截图素材
2. 判决不止于玩笑：每个段位都会落到**真实的优惠券与点餐方案**上（`available-coupons` / `query-my-coupons` / `query-nearby-stores` / `query-meals` / `calculate-price`），让「审判」完成从情绪价值到实用价值的闭环
3. 评分引擎离线可用、确定性可复现，配合 MCP 实时数据构成「离线可玩、在线更强」的双层体验

详细工具调用链路见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。
